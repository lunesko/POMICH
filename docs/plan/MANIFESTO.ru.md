# Манифест POMICH

## POMICH — допомога вже їде.

Автомобиль может остановиться в любой момент. Разряженный аккумулятор, пробитое колесо, закончившееся топливо, неисправность или ДТП превращают обычную поездку в ситуацию, где человек внезапно остаётся один на дороге.

Сегодня поиск помощи часто выглядит одинаково: открыть Google, звонить по нескольким номерам, объяснять, где ты находишься, ждать ответа, выяснять цену, снова ждать и надеяться, что исполнитель действительно приедет.

Мы считаем, что помощь автомобилисту должна вызываться так же просто, как сегодня вызывается такси.

Это и есть POMICH.

## Что мы строим

POMICH — это on-demand сеть помощи автомобилистам.

- Не каталог эвакуаторов.
- Не доска объявлений.
- Не ещё один навигатор.
- Не служба с собственным парком машин.

Мы строим технологическую платформу, которая в момент проблемы соединяет автомобилиста с подходящим исполнителем рядом.

Пользователь должен сделать несколько простых действий:

```text
открыть POMICH → указать проблему → подтвердить местоположение → увидеть условия → вызвать помощь
```

После этого система сама занимается остальным:

```text
ПРОБЛЕМА
  ↓
ГЕОЛОКАЦИЯ
  ↓
POMICH DISPATCH
  ↓
ПОДХОДЯЩИЕ ИСПОЛНИТЕЛИ РЯДОМ
  ↓
ПЕРВЫЙ ПОДТВЕРЖДАЕТ
  ↓
ИСПОЛНИТЕЛЬ НАЗНАЧЕН
  ↓
ПОМОЩЬ ЕДЕТ
  ↓
ПРИБЫТИЕ
  ↓
РАБОТА ВЫПОЛНЕНА
```

Человек не должен искать помощь. Помощь должна сама найти человека.

## Миссия

Сделать получение помощи на дороге быстрым, прозрачным и предсказуемым в любой точке, где есть автомобиль и исполнитель.

Фраза «У меня сломалась машина» должна означать: **«Я открыл POMICH. Помощь уже едет.»**

## Какой продукт мы хотим построить

POMICH должен стать для roadside assistance тем, чем Uber, Bolt и Uklon стали для городских поездок.

Но механика обратная.

В такси: водитель приезжает → забирает человека → везёт его.  
В POMICH: исполнитель приезжает → к сломанному автомобилю → и решает проблему.

За одной кнопкой POMICH со временем должна находиться целая сеть: эвакуаторы, запуск аккумулятора, помощь с колесом, доставка топлива, открытие автомобиля и мобильные механики.

Пользователь сообщает что произошло. POMICH решает кого отправить.

## Главный принцип

**Не ближайший исполнитель. Лучший исполнитель для конкретной ситуации.**

```text
тип проблемы
+ возможности исполнителя
+ местоположение
+ доступность
+ ETA
+ вероятность принятия
+ история выполнения
+ загрузка
= BEST PROVIDER
```

Ключевая метрика — **Time To Rescue**: от создания заявки до прибытия реальной помощи.

## Карта — это не продукт

Google знает, как ехать. POMICH знает, кого отправить.

Карта в POMICH — интерфейс инфраструктуры. На старте: OpenStreetMap + собственный dispatch-слой.

## POMICH Partner

Исполнитель открывает POMICH Partner и нажимает **Вийти на лінію**.

Когда рядом появляется подходящая заявка — первый подходящий, кто подтверждает, получает заказ.

```text
ASSIGNED → EN_ROUTE → ARRIVED → IN_PROGRESS → COMPLETED
```

## Asset-light

Мы не владеем тысячами эвакуаторов. Мы объединяем существующий рынок единой системой мгновенного доступа.

## Сначала Украина

```text
1 город → 10 исполнителей → 100 реальных заявок → 1000 заявок → несколько городов → вся Украина
```

Затем модель переносится на другие страны. Цель — глобальный technological layer для roadside assistance.

## OpenRoadAid

- **POMICH** — продукт и marketplace
- **OpenRoadAid** — протокол и инфраструктурный слой

```text
incident → capabilities → matching → offer → assignment → arrival → completion
```

## Главный актив

```text
Verified Provider Network
+ Historical Incidents
+ Provider Reputation
+ Real TTR Data
+ Dispatch Engine
+ Demand / Supply Map
+ Pricing Intelligence
+ Integrations
```

Каждая выполненная заявка делает сеть умнее.

## Принципы

1. Сначала помощь — потом функции (фильтр: сокращает ли TTR?).
2. Реальность важнее красивой демо-версии.
3. Пользователь не обязан понимать рынок.
4. Цена понятна заранее.
5. Исполнитель должен видеть ценность платформы.
6. Навигацию не изобретаем заново.
7. Безопасность и доверие — часть продукта.
8. Архитектура должна позволять стать API.

Для клиента: **POMICH — допомога вже їде.**
