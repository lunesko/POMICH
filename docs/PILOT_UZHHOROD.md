# Пілот POMICH: Ужгород

## Межі пілота

- Нові заявки: евакуатор або запуск АКБ, місце подачі в радіусі 15 км від центру Ужгорода.
- Заявка приймається, лише якщо поблизу є хоча б один вільний перевірений партнер потрібної спеціальності. Пошук автоматичний: пропозиції надходять партнерам на лінії; клієнтський оператор не передбачений.
- Якщо партнера не знайдено за 180 секунд, пошук завершується повідомленням про відсутність виконавця. Заявка не залишається у вічному очікуванні.
- Telegram використовується для сповіщень партнерів. Клієнт може користуватися сайтом без Telegram через наявний вебсеанс та підтвердження профілю.

## Ціна

Погоджених тарифів партнерів поки немає. Тому сайт не показує розрахунок як остаточну ціну. Партнер пропонує повну ціну, а клієнт підтверджує її **до виїзду**. Це тимчасове правило: автоматичне прийняття за фіксованим тарифом потребує письмово погоджених тарифів і правил для нестандартних випадків. Публічні прайси конкурентів не є тарифами POMICH.

## Налаштування

У production `POMICH_PILOT_MODE` вмикається за замовчуванням. У Vite `VITE_POMICH_PILOT_MODE` також увімкнений за замовчуванням. Для узгодженого відображення зони задавайте однаковий радіус у `POMICH_PILOT_RADIUS_KM` та `VITE_POMICH_PILOT_RADIUS_KM` до збірки фронтенду. `POMICH_SEARCH_TIMEOUT_SECONDS` керує граничним часом пошуку. При порожній базі в режимі пілота демонстраційні партнери не створюються.

## Умови запуску

Перед публічним запуском потрібно зареєструвати реальних перевірених партнерів обох спеціальностей, перевірити доставку пропозицій у Telegram, погодити ціну та правила її зміни, а також перевірити вебреєстрацію клієнта без Telegram на реальному пристрої. Поки немає погоджених тарифів, не слід рекламувати «фіксовану ціну» або «партнер виїде одразу після заявки».
